## 👋 About Me

I'm **Emmanuel Ejeagha**, a backend-focused software engineer interested in building reliable, maintainable and financially accurate systems.

My primary backend stack is **C#/.NET and ASP.NET Core**. I'm also developing my skills in **TypeScript and Node.js** to build modern APIs and SaaS backends.

I enjoy working on problems where transaction correctness, system reliability, security and clear architecture matter — particularly in **FinTech, payment infrastructure and distributed systems**.

**What I bring to a project**
- Backend API design and implementation
- Clean Architecture, DDD and CQRS
- Payment and ledger system concepts
- Relational databases and data integrity
- Asynchronous messaging and service integration
- Linux, troubleshooting and systems support
